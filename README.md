# ☕ Coffee Lab - Website Oficial

Seja bem-vindo ao repositório do site **Coffee Lab**, uma plataforma web desenvolvida para apresentar a nossa cafeteria artesanal e o nosso catálogo exclusivo de cafés especiais localizados em Copacabana, Rio de Janeiro.

---

## 📌 Sobre o Projeto

O **Coffee Lab** é um site moderno e responsivo focado na experiência do cliente, permitindo explorar os nossos cafés mais pedidos, visualizar detalhes das xícaras (como o **Aroma Imperial**, **Ponto Torrado** e **Urban Bean**), consultar preços e conhecer o nosso conceito focado na ciência do sabor perfeito.

---

## 🛠️ Tecnologias Utilizadas

- **React.js** - Biblioteca principal para construção da interface.
- **CSS3** - Estilização moderna, responsiva e personalizada.
- **JavaScript (ES6+)** - Lógica da aplicação e manipulação de dados.
- **HTML5** - Estruturação semântica do conteúdo.
